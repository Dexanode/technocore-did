# Contributing

Pull request diprioritaskan untuk koreksi teknis, contoh yang sudah diuji,
penjelasan ramah pemula, dan troubleshooting yang dapat direproduksi.

Sebelum submit:

- pastikan tidak ada private key atau credential;
- sertakan sumber untuk klaim protokol;
- jelaskan siapa yang terbantu oleh perubahan;
- hindari klaim bahwa aktivitas tertentu menjamin reward;
- jalankan `git diff --check`.
